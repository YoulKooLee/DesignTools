# 第五轮 · 按设计稿落地界面骨架（方案）

> 起因：用户对照 `设计稿_图表设计_三入口.html`（11-25 09:45 交付）指出，实际弹窗与设计稿差距很大。

## 零、先说清楚为什么会偏

不是"忘了"，是执行方式错了：

| 时间 | 做了什么 | 问题 |
|---|---|---|
| 11-25 09:45 | 交付设计稿（三入口 + 表头 + 分组 + 开关 + 5 步 stepper + 右栏摘要 + 底部 meter） | — |
| 11-25 10:00 起 | 阶段 1–4 落地**功能**：三入口标签、钻取面包屑、菜单 3–8、按菜单隔离、指标两属性、上屏/下屏、容量护栏 | 只落"能力"，没落"长相" |
| 11-25 12:00 | **列表重排**（我自己判断成"四段式 + 行尾按钮"） | 与设计稿的"表头 + 分组 + 开关"**正面冲突**，越改越远 |

一句话：**我把设计稿当成了"功能清单"，它其实是"界面蓝图"。** 后续每轮都在旧骨架上打补丁，补丁越多，离蓝图越远。这份方案就是把骨架换回蓝图，同时保住后四轮补出来的功能。

## 三、需要你裁决的 5 个冲突点

### R1 · 上屏交互：开关 vs 按钮

- 设计稿：左侧 `switch` 拨杆（开=上屏），另外"点样式即上屏"。
- 现状：行尾 `上屏 / 下屏` 文字按钮，样式只管形状。
- **建议**：**用开关的形态，保留显式语义** —— 左侧放 switch 拨杆控制上屏/下屏，样式 chip 只管形状（不再"点样式即上屏"，因为上一轮就是因为隐式上屏导致"找不到怎么上屏"）。等于"设计稿的壳 + 现状的核"。

### R2 · 展示形式：胶囊 vs 方按钮

- **建议**：改成设计稿的**胶囊形态**（圆角 11px、10.5px 字），但保留现状的 `荐`角标和 `更多`收折（7 个样式全摊开会把行高撑乱）。
- 数量：设计稿每行 3–4 个胶囊（不折行）；现状默认 3 个 + 更多，一致。

### R3 · 底部按钮

- 设计稿：`取消` + `确认选择`
- 现状：`随机选取` + `完成`
- **建议**：`取消` 删掉（取消语义已统一为即时生效，× 就等于完成）；保留 `随机选取` + `完成`。

### R4 · `已选清单` chip 区要不要留

- 设计稿没有，现状有（底部一块 chip 列表 + `改完即时生效，还可再选 N 项`）。
- **建议**：删掉。信息已由三处覆盖：行内位次、底部 meter、表头。删掉后弹窗高度更宽裕，正好放设计稿的 lfoot。

### R5 · 数据管理要不要"载入示例"

- 设计稿有 `示例数据 → 载入示例` 按钮（一键灌一张内置演示表）。
- 现状没有（只有 `样例数据.csv` 文件在目录里）。
- **建议**：补上，直接读同目录 `样例数据.csv` 不行（file:// 下 fetch 本地文件会被拦），改成**内嵌一份精简版**（约 60 行，覆盖 3 维度 + 2 度量）作为"载入示例"。

| # | 现象 | 根因 | 修法 |

| 1 | 底部进度条到 12/12 仍是蓝色，用户以为还能再加 | `.warn` 绑的是 `已用 > 总数`，满位不触发 | 进度条与数字改用 `full = 已用 >= 总数`；头部那行数字仍只在真超位时变橙（两条语义分开） |

| 3 | 关掉再打开同一指标，形状从 KPI 变成柱图 | 上屏时按 `defaultType()` 重算而非记住上次 | 加 `LAST_TYPE` 记忆：关时存、开时优先取（第四轮已修，本轮回归覆盖） |
