# 方案：「图表设计」层级重构（v1，待拍板）

日期：2026-11-25　文件：`泛卓办公/大屏编辑器/大屏编辑器.html`（根目录副本同步）
前置：上一轮已完成「大屏设计器→图表设计」改名 + 删除「② 指标」标签（备份 `大屏编辑器.bak-20261125-删指标步骤前.html`）

## 一、要解决的问题

| 现状 | 根因 |
|---|---|
| `② 维度计算` 是个动作（新建/编辑指标的 5 步表单），却和「数据」「图表」并列成标签 | 动作与对象混在同一层级 |
| 指标清单藏在 `③ 图表` 里，和文案配置、已选清单挤在一起 | 缺少「指标」这个对象的独立入口 |
| 指标管理的编辑/删除散落在两处（维度计算底部的管理卡 + 图表面板的行内按钮） | 同一职责两个落点 |
| 上屏是隐式动作（点样式胶囊=上屏，再点=取消） | 「是否上屏」和「什么形式」两个概念被压成一个手势 |

## 二、目标结构

```
图表设计
├─ 文案配置      大屏标题 · 菜单个数 · 菜单名称 · 应用文案
├─ 数据管理      上传 / 管理明细事实表（+ 清空全部数据）
└─ 指标管理      指标清单：上屏开关 · 展示形式 · 编辑 · 删除 · 添加
     └─ 添加 / 编辑  → 维度计算（同窗钻取，面包屑「指标管理 / 新建指标」）
          选事实表 → 标字段角色 → 定聚合方式 → 时间粒度 → 真算预览 → 保存返回
```

- 打开弹窗默认落在**指标管理**。
- `维度计算` 不再出现在标签栏，只作为钻取视图存在。

## 三、指标管理：行规格

| 区域 | 内容 |
|---|---|
| 左：上屏开关 | 单一「是否上屏」开关；关闭状态点样式胶囊会顺手打开开关并选中该形式 |
| 中：名称与口径 | 名称 + `示例`/`自定义` 标签 + 模块；第二行 示例=单位/维度/来源，自定义=事实表 · 汇总方式 · 度量字段 |
| 中：维度 | 自定义指标只读展示（维度由维度计算锁死）；示例指标沿用现可点维度胶囊 |
| 右：展示形式 | **保留一排样式胶囊**（按维度数过滤，1 维 / 2 维两档）；点胶囊=换形式，**不再承担取消上屏** |
| 右：操作 | `编辑`（仅自定义）、`删除`（全部，示例删除=隐藏可恢复） |
| 分组 | 「自定义指标」置顶，其次「示例指标」；示例组标题右侧给「已隐藏 N 条 · 恢复」 |
| 顶栏 | 搜索 + 模块筛选 + `全部 / 仅已上屏` + 命中计数（替换现有「全部/已选KPI/已选图表」） |

**删掉的东西**：`③ 图表` 里的「已选清单」条（列表本身已表达上屏状态），底部只保留 `KPI 3/3 · 图表 4/12` 计数与「确认选择」。

## 四、已拍板的四条规则

1. **示例指标**：只读可删。4 条示例可逐条删除（删除=从列表隐藏，持久化），提供「恢复」入口。不可编辑（无事实表可配）。
2. **上屏超限**：图表位 12 / KPI 位 3（随布局变）满时，**拒绝**并提示「图表位已满 12/12，请先关闭一张」，同时高亮已上屏行。不再自动顶掉最早一张（`makeRoom` 的上屏路径停用）。
3. **展示形式**：保留一排样式胶囊。
4. **钻取方式**：同窗内切换视图 + 面包屑「指标管理 / 新建指标」，保存或取消都回到指标管理。

## 五、配套细则（我按常识定的，可逐条否决）

| # | 细则 | 理由 |
|---|---|---|
| 1 | 「清空全部数据」从文案配置移到**数据管理底部** | 它清的是数据表+自定义指标+布局存档，和标题菜单无关 |
| 2 | 编辑已有指标**从第 1 步开始**（现为第 4 步） | 想改事实表得自己往回点三下 |
| 3 | 取消/返回时若有改动 → `确认放弃未保存的配置？` | 现在直接丢，5 步白填 |
| 4 | 保存后**自动上屏**（受容量约束；满了只保存不上屏并提示） | 保留现有「保存即可用」的手感 |
| 5 | 删除示例若已上屏 → 一并移出，卡片位留空 | 与自定义指标的删除口径一致 |
| 6 | 隐藏示例 persisted 在 `ds_hidden_base` | 前缀 `ds_` 能被「清空全部数据」扫到，一并复位 |

## 七、验收清单（CDP 实测）

- V1 三个入口切换 + 默认落在指标管理
- V2 添加 → 5 步 → 保存 → 回列表高亮 + 自动上屏（计数 +1）
- V3 编辑 → 停在第 1 步 → 改聚合方式 → 保存覆盖原行
- V4 取消：有改动弹确认、无改动直接返回
- V5 上屏开关开/关；池满时拒绝并提示、计数不变、已上屏行高亮
- V6 胶囊换形式不改开关状态；开关关闭时点胶囊自动打开
- V7 删除自定义指标 → 行消失、已上屏卡片移除
- V8 删除示例 → 隐藏；「已隐藏 1 条 · 恢复」可用；恢复后回来
- V9 刷新后：隐藏状态、上屏选择、布局都还在
- V10 文案配置改动生效；清空全部数据在数据管理底部且执行后示例复位
- V11 搜索 / 模块筛选 / 仅已上屏 结果正确
- V12 1280×800 下弹窗无横向溢出（开关与胶囊不换行错位）

## 八、这轮不做（避免范围膨胀）

- 同一指标上屏多张卡（现模型 `selItems` 按 `ind` 唯一，要改数据模型与布局映射）
- 行内改自定义指标的维度（维度由维度计算锁死，改维度走编辑）
- 示例指标「复制为自定义」
- 指标清单换成真表格（列对齐、批量操作）

## 九、风险

1. **删掉示例后大屏空位**：图表位有 12 个，示例只有 4 条，删光示例后上屏项为空，布局里可能出现空卡位。需实测确认 `renderScreen()` 对缺失 `selItems` 的兜底（留空/占位），并在删除提示里写明。
2. **双控件心智**（开关 + 胶囊）：靠一句行内提示「点样式即上屏，关闭开关取消」消化，若你觉得还是绕，下一步可退化成“只有胶囊、顶部显示上屏计数”。
3. **默认标签变更**：`openModal()` 里有旧的 tab 初始化逻辑，需一并改，否则首次打开可能空白。

## 十、设计稿（2026-11-25）

独立原型：`大屏编辑器/设计稿_图表设计_三入口.html`（单文件、无依赖、可直接点）。
用途：先看结构与排版，确认后再落到 `大屏编辑器.html`。

设计稿相对本方案的三处调整（实施时按设计稿走）：

1. **指标行改横向布局**：`[上屏开关] [名称+口径+维度胶囊] [上屏位次] [展示形式] [操作]`，维度不再单独成列，避免名称列过宽留出大片空白；新增「上屏位次」（图表 01 / KPI 01 / 未上屏），关开关后序号自动重排。这也是方案里没提但实测必要的信息。
2. **文案配置改左右两栏**：左侧大屏预览（标题+菜单+四块图表占位，可拉伸）+ 表单；右侧「当前状态 / 填写建议」。清空全部数据按方案放在数据管理底部。
3. **向导右侧加「配置摘要 + 上屏约束」**：摘要按当前步骤高亮对应行（第 1 步事实表/名称、第 2 步维度、第 3 步度量、第 4 步粒度、第 5 步形式）；第 1 步补事实表前 3 行数据预览。

设计稿实测：三入口切换、开关上下屏与位次重算（图表 01–05）、点胶囊自动上屏、删除示例与恢复、仅已上屏筛选、钻取到第 3 步摘要高亮、保存返回列表，全部通过且无 JS 报错。
